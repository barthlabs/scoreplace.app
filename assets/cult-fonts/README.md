# Fontes do regulamento CULT

Fontes abertas servidas localmente, obtidas em 25/11/2026 pela API oficial Google Fonts:
https://fonts.googleapis.com/css2?family=DM+Sans:wght@500;600;700;800&family=Instrument+Serif:ital@1&display=swap

- cult-1.ttf a cult-4.ttf: DM Sans, pesos 500, 600, 700 e 800.
- cult-5.ttf: Instrument Serif, itálico, peso 400.
- Licenças SIL Open Font License 1.1: dmsans-OFL.txt e instrumentserif-OFL.txt, obtidas de https://github.com/google/fonts/tree/main/ofl/dmsans e https://github.com/google/fonts/tree/main/ofl/instrumentserif.

A seleção tipográfica foi feita por aproximação visual das capturas; os arquivos de fonte da página original não foram disponibilizados. Os arquivos permanecem inalterados e conservam os nomes internos das famílias.
